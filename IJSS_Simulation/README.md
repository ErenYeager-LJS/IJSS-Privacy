# IJSS-Privacy Numerical Reproduction

This package executes one illustrative four-DG, two-stage numerical case under
the frozen `LOCAL-BEFORE-EXIT` claim boundary. It shows droop-only operation,
switched secondary response, engineering-unit voltage/frequency trajectories,
an active-power sharing preservation diagnostic, and one finite privacy witness.
It does not prove prescribed-time recovery, active-power sharing, global
continuation, invariance, or all-time privacy.

`canonical_parameter.yaml` is the sole parameter source. The separated Python
pipeline is:

```text
simulation -> raw NPZ -> processed NPZ -> five Origin CSVs -> five figures
```

Run from the repository root:

```powershell
$env:PYTHONPATH="$PWD\IJSS_Simulation\Python\src"
python IJSS_Simulation/Python/src/solver/run_all.py
python IJSS_Simulation/Python/src/processing/build_processed_data.py
python IJSS_Simulation/Python/src/export/export_origin.py
python IJSS_Simulation/Python/src/plotting/generate_figures.py
```

The five CSVs are `Voltage.csv`, `Frequency.csv`,
`ActivePowerSharing.csv`, `PublicHistory.csv`, and `PrivateDifference.csv`.
Every figure is exported as PDF, SVG, and 300-dpi PNG.

## Simulink

`Simulink/main.slx` is generated by
`MATLAB/scripts/build_and_run_simulink.m`. Its top level contains DG1--DG4,
electrical and power calculation layers, primary droop and secondary controller
layers, an explicit secondary activation switch, communication, privacy,
logging, and scopes. It uses basic Simulink blocks, with no S-function or
MATLAB Function block. The model reproduces P1; W1 remains Python-only.

The configured StopTime is `15 s`. Voltage and frequency scopes use `V` and
`Hz`; separate voltage-error (`V`) and frequency-error (`Hz`) scopes are
included. Under the current parameter instance the local trajectory reaches
no PPC admissibility exit through `15 s`, while a basic-block guard remains
available to stop the simulation at any detected boundary. The selected-run
statement `t_exit > 15 s` is not an invariance or continuation claim.

The 32-state Python--Simulink comparison passes the frozen `1e-5` absolute
threshold on the full `0--15 s` interval. RT-LAB target compilation,
partitioning, I/O mapping, and hardware execution still require the user's
RT-LAB environment.
